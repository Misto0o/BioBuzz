# Triple Paradox — FTC Team 6183

Robot code for **BIOBUZZ** (2026–2027), built on the FTC SDK 11.2.1 with
[Pedro Pathing](https://pedropathing.com) 3.0.0.

Our code lives in [`TeamCode/src/main/java/org/firstinspires/ftc/teamcode/`](TeamCode/src/main/java/org/firstinspires/ftc/teamcode) —
see the readme in that folder for subsystem details, hardware config, and tuning notes.

Everything outside `TeamCode/` is the stock FTC SDK.
